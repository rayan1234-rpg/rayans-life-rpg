RAYAN'S LIFE RPG — V2.0 ANDROID APK (ഫോൺ ഉപയോഗിച്ച്)

1. ZIP ഫയൽ Extract ചെയ്യുക.
2. GitHub repository തുറക്കുക.
3. Add file > Upload files തിരഞ്ഞെടുക്കുക.
4. ZIP-ൽ Extract ചെയ്ത എല്ലാ ഫയലുകളും upload ചെയ്യുക. .github ഫോൾഡറും ഉൾപ്പെടുത്തണം.
5. Commit changes അമർത്തുക.
6. Actions tab തുറക്കുക.
7. "Build Android APK" workflow തിരഞ്ഞെടുക്കുക.
8. Run workflow അമർത്തുക.
9. Build വിജയിച്ചാൽ workflow run തുറന്ന് Artifacts ഭാഗത്ത് നിന്ന് rayans-life-rpg-debug-apk download ചെയ്യുക.
10. Download ചെയ്ത artifact ZIP Extract ചെയ്യുക.
11. app-debug.apk തുറന്ന് Android ചോദിച്ചാൽ install permission അനുവദിക്കുക.

പുതിയ V2.0 സവിശേഷതകൾ:
- Offline Focus Academy: Memory Trial, Number Sequence, Pattern Focus.
- ഓരോ Focus game-നും ദിവസത്തിൽ ഒരിക്കൽ +10 XP, +5 Coins.
- അഞ്ച് Demon Warrior evolution stages.
- CSS 3D-style cinematic evolution scene.
- പഴയ missions, skills, MMA, drawing journal, hygiene mission, backup/restore എന്നിവ നിലനിർത്തിയിട്ടുണ്ട്.

ശ്രദ്ധിക്കുക:
- Mini-games offline പ്രവർത്തിക്കും; live AI service ആവശ്യമില്ല.
- Evolution scene 3D-style CSS animation ആണ്; യഥാർത്ഥ 3D model അല്ല.
- Progress ഈ browser/device-ൽ മാത്രം save ചെയ്യുന്നു. Backup export ചെയ്യുക.
- GitHub Actions വഴി APK build ചെയ്യാൻ internet connection ആവശ്യമാണ്.
- ഇത് debug APK ആണ്; Play Store release signing ഉൾപ്പെടുത്തിയിട്ടില്ല.
